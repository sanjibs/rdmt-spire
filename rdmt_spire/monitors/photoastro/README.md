# Photometry Monitor
This monitor will analyse an L2 file and its associated source catalog file. The L2 file is an image generated by the Roman WFI instrument, while the source catalog is a table of sources identified in the L2 image by the `romancal` pipeline. 

The source catalog contains position and photometric information of both point like ( e.g., stars) and extended sources (e.g., galaxies) identified by romancal in an L2 image. The monitor selects point sources from the source catalog with property (`is_extended=False`). 
It runs PSF photometry (`photutils.PSFPhotometry`) on the L2 image to estimate the position and flux of selected point sources, starting with true coordinates based on the source catalog. It also runs aperture photometry (`photutils.aperture.aperture_photometry`) on the L2 image to estimate the aperture flux of selected point sources. 

The monitor then compares the estimated fluxes with the fluxes reported in the source catalog and computes a set of metrics to assess the performance of the photometry pipeline.

It splits sources into two bins based on their brightness, a `bright` bin and a `faint` bin. The bright bin contains sources with magnitude between the saturation limit and the midpoint between the saturation limit and the faint limit. The faint bin contains sources with magnitude between the midpoint and the faint limit. The saturation limit is determined by the exposure time and the filter used for the observation, while the faint limit is determined by the background noise level in the image. 

It does a cross match with gaia to identify common sources between the L2 image and the Gaia catalog. Statistics of angular separation to Gaia sources is reported to assess the astrometric accuracy of the L2 image.


## Implementation details
The monitor class initializer accepts two arguments, `asdf_file` which is the L2 image file and a `config` dictionary, containing directory paths.
The source catalog file name is derived from the base L2 image filename (`asdf_file['roman']['meta']['filename']`) by replacing suffix `_cal.asdf` with `_cat.parquet`. The path to the source catalog file is specified by `config['RMDT_L4_SOURCE_DIR']`.
